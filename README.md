# ai-lab

[한국어 README](README.ko.md)

A personal workspace for building and testing AI ideas. It currently includes LLM Wiki and
SubBrain.

## LLM Wiki

**Status: in development**

LLM Wiki stores source material and notes made from it on the local machine. The notes are Markdown
files that people can read and edit directly.

It can:

- preserve a copy of each source;
- organize summaries and notes drawn from one or several sources;
- find relevant documents for a question;
- give an AI the relevant source material along with a task, so people can check what its answer is
  based on; and
- keep AI-written documents as drafts, then add them to the Wiki only after a person reviews and
  accepts them.

## SubBrain

**Status: paused**

SubBrain is an experimental tool that runs locally.

It can:

- organize user-provided records into separate events and store them locally;
- find past records that may be relevant to a new question; and
- show which records support a possible connection and what remains uncertain instead of treating
  that connection as a confirmed cause.

SubBrain does not collect personal data automatically.
